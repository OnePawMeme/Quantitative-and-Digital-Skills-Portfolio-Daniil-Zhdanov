# Project 1: Portfolio and Investment Analysis

## Project Overview
This project involves a comprehensive statistical analysis of financial assets to evaluate their risk-return profiles. The analysis compares major equities (Intel vs. AMD) and mutual funds (Growth vs. Value) to provide data-driven investment insights.

## Quantitative and Digital Skills Demonstrated
Conducted a comprehensive portfolio and investment analysis using Excel to evaluate the risk-return profiles of major equities (e.g., Intel, AMD). Demonstrated proficiency in financial data manipulation by calculating daily and weekly returns, mean absolute deviations, variances, and standard deviations. Applied advanced statistical inference, including Chi-Square tests and F-tests for two population variances, to compare investment risks. Evaluated portfolio performance using key financial metrics such as covariance, correlation, the Coefficient of Variation (CV), and the Sharpe Ratio.
