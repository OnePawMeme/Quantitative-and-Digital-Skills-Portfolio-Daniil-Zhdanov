# Project 2: Customer Base Audit

## Project Overview
This project focuses on evaluating a company's customer base to identify key revenue drivers, analyze purchasing behavior, and assess customer retention across different historical cohorts.

## Quantitative and Digital Skills Demonstrated
Executed a comprehensive Customer Base Audit using Excel to identify revenue drivers and assess customer retention. Demonstrated strong data structuring skills by performing decile and cohort analyses on complex transaction data across multiple fiscal quarters. Calculated and interpreted critical business KPIs, including Average Order Frequency (AOF), Average Order Value (AOV), average spend per active customer, and profit margins. Effectively visualized data distributions using histograms, ogives, and scatterplots to uncover actionable business insights.
